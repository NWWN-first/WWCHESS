* 좌석 편향의 결정적 원인 코드 분석:
  1) 동시 탈락자 순위 산정의 배열 순서 종속성 (src/GameLoopManager.ts:1076~1081):
     - 한 라운드에서 여러 참가자가 체력 <= 0으로 동시 탈락할 때:
       for (const p of this.participants) { if (p.hp <= 0) this.eliminationOrderIds.push(p.id); }
     - this.participants의 배열 순서는 항상 [player, ai_bot_1, ai_bot_2, ..., ai_bot_7] 입니다.
     - 따라서 같은 라운드에 동시 탈락하면 ai_bot_1이 eliminationOrderIds의 앞쪽에 먼저 push됩니다.
     - 순위 부여 식은 placements.set(id, 8 - idx) 입니다.
     - 즉, 배열 앞쪽에 있는 ai_bot_1은 항상 8위(또는 7위)를 받고, 뒤쪽에 있는 ai_bot_7은 7위(또는 6위)를 받게 됩니다!
     - 실제 3,000판 중 한 라운드 동시 탈락 발생 라운드: 3347회 / 17354회 (19.3%).
     - 이것이 ai_bot_1(평균 4.26위)보다 ai_bot_7(평균 4.08위)의 순위가 구조적으로 더 좋게 나오는 가장 핵심 원인입니다.
  2) 대진 셔플 비균일성 (src/GameLoopManager.ts:872):
     - aliveList.sort(() => Math.random() - 0.5) 는 V8 엔진에서 균등하지 않은 셔플로, 앞뒤 인덱스에 편향을 유발합니다.
  3) 공유 풀 선점 순서 (src/GameLoopManager.ts:576~588):
     - 매 라운드 시작 시 상점 롤을 돌릴 때 this.participants 순서대로 기물을 풀에서 인출하므로 앞쪽 봇이 기물을 먼저 선점합니다.
